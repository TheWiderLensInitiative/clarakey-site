# ClaraKey website

The site for [ClaraKey](https://github.com/TheWiderLensInitiative/clarakey), the portable offline encrypted vault:
https://clarakey.thewiderlens.info

Static HTML, deployed by Vercel on every push to `main`.

- `index.html`: the home page
- `privacy.html`: generated from `docs/PRIVACY.md` in the ClaraKey repo; keep them the same
- `assets/`: logo and icon (from the app's `brand/`), Montserrat (OFL), screenshots (demo vault), social card
